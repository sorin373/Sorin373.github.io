## Engineering problem

Observed altitude differs from true geometric altitude due to atmospheric refraction. The model needs to separate geometry, input configuration, correction terms and result generation.

## Methodology

- Define input altitude, pressure and temperature parameters
- Apply apparent-to-true altitude correction
- Export tabular results for inspection
- Compare outputs against trusted references before claiming validation
